# Ernest Raday — Frutiger Aero Resume

Live resume with an embedded PDF and auto-updating TryHackMe streak / rooms, themed in **Frutiger Aero** (glossy glass, sky–grass nature tech, Y2K chrome accents).

**Site:** https://ejrad.github.io/resume/  
**Frutiger Aero:** https://ejrad.github.io/resume/frutiger/

```bash
npm install
npm run update:demo
npm run dev
```
